## 🛠️ Tech Stack & Architecture

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org) + [React 19](https://react.dev)
- **Styling:** [Tailwind CSS](https://tailwindcss.com) with custom monochrome editorial design tokens (`#0B0B0B` Obsidian, `#121212` Elevated Noir, `#E8E5DE` Archive Paper, `#EF5B53` Signal Red).
- **Typography:** `@next/font/google` loading Space Grotesk, DM Sans, and IBM Plex Mono with `display: "swap"`.
- **Canvas & Graphics:** Deferred 3D orbital particle void (`ComputationalVoid`) running at 60fps with `IntersectionObserver` pause-on-scroll (`0% GPU` when off-screen).
- **Portrait Pipeline:** Non-destructive CSS Black & White layer (`grayscale(100%) contrast(1.12) brightness(0.96)`) and seamless `#000000` to `#0B0B0B` obsidian vignette blending with local file binding and `localStorage` persistence.
- **AI Discoverability:** Strict `llms.txt` specification compliance (`/llms.txt` and `/ai.txt`) with an embedded `schema.org/Person` JSON-LD payload.

## 🚀 Quickstart

### Prerequisites
- Node.js `18.18+` or `20+` / `25+`
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Harshkr4227/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the live application.

### Production Build
```bash
# Generate optimized static production build
npm run build

# Start production server locally
npm run start
```
